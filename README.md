# TODOアプリ

## 概要

自分のやることを簡単に管理するTODOアプリです。

## 使用技術

- HTML
- CSS
- JavaScript

## 主な機能

- TODOの追加
- TODOの編集
- TODOの削除
- 完了チェック
- データ保存
- スマートフォン対応

## 工夫した点

- localStorageを使用して、ページを再読み込みしてもTODOが残るようにしました。
- スマートフォンでも使用できるようにレスポンシブ対応しました。

## ワイヤーフレームについて

制作前に手書きでワイヤーフレームを作成しました。

実際に実装していく中で、使いやすさや画面の見やすさを考えて、
一部のレイアウトやデザインを変更しました。

そのため、ワイヤーフレームと完成したアプリでは
一部異なる部分があります。

## 制作した理由

やることを頭の中だけで管理すると忘れてしまうため、
簡単に記録して確認できるアプリを作りました。
